# GLX Engenharia

Site institucional da GLX Engenharia, desenvolvido em Next.js e publicado na Vercel.

- Produção: https://glx-engenharia.vercel.app
- Deploy: conectado à branch `main` deste repositório

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

## Verificação

```bash
pnpm lint
pnpm build
```

Toda alteração concluída deve ser validada, commitada e enviada para `main`. A integração entre GitHub e Vercel publica automaticamente o novo commit em produção.
