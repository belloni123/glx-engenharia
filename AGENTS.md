# Instruções do projeto

- Considere este repositório a fonte oficial do site da GLX Engenharia.
- Depois de cada alteração solicitada e validada, registre um commit claro e envie a branch `main` para o GitHub.
- Confirme que o deploy automático da Vercel terminou com sucesso antes de concluir o trabalho.
- O endereço de produção é `https://glx-engenharia.vercel.app`.
- Não inclua `.env`, credenciais, `node_modules`, `.next`, `dist` ou arquivos locais da Vercel no Git.
